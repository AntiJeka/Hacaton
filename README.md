# README.md

## Система анализа ТН ВЭД

Веб-приложение для анализа товаров по кодам ТН ВЭД и получения рекомендаций по мерам таможенно-тарифного регулирования.

### Описание проекта

Система предоставляет предприятиям инструмент для анализа товаров по товарной номенклатуре внешнеэкономической деятельности (ТН ВЭД) и получения рекомендаций по мерам таможенно-тарифного регулирования. Приложение анализирует статистику импорта, объемы производства и потребления, а также другие экономические показатели для формирования оптимальных мер регулирования.

### Функциональность

- **Анализ товаров по коду ТН ВЭД** (6 или 10 знаков)
- **Отображение статистических данных**:
  - Основная информация о товаре
  - Аналитические показатели (доля недружественных стран, производство vs потребление)
  - Объемы импорта и динамика изменений
  - Тарифная информация (ставки пошлин)
  - Объемы производства и потребления по годам
  - Нормативная информация (сертификация, госзакупки, приказы)
- **Рекомендации по мерам регулирования** на основе алгоритмического анализа
- **Топ-10 стран по СКЦ** (стоимость за килограмм)

### Алгоритм принятия решений

Система использует сложный алгоритм для определения рекомендуемых мер регулирования:

1. **Анализ доли импорта из недружественных стран**
2. **Оценка динамики импорта** (рост/снижение)
3. **Сравнение объемов производства и потребления**
4. **Учет нормативных ограничений** (сертификация, госзакупки)

На основе этого анализа система рекомендует одну из шести мер регулирования:

- **Мера 1**: Снижение ставки ввозной таможенной пошлины
- **Мера 2**: Введение специальных защитных мер
- **Мера 3**: Введение антидемпинговой пошлины
- **Мера 4**: Введение тарифной квоты
- **Мера 5**: Техническое регулирование и сертификация
- **Мера 6**: Поддержка экспорта продукции

### Установка и запуск

#### Требования
- Java 17 или выше
- Maven 3.6+
- Современный веб-браузер

#### Сборка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/AntiJeka/Hacaton
cd tnved-analysis-system
```

2. Соберите проект:
```bash
mvn clean package
```

3. Запустите приложение:
```bash
java -jar target/demo-0.0.1-SNAPSHOT.jar
```

4. Откройте в браузере:
```
http://localhost:8080/main
```

### Использование

1. Введите код ТН ВЭД (6 или 10 цифр) в поле ввода
2. Нажмите кнопку "Провести анализ"
3. Изучите полученные результаты и рекомендации

### Формат данных

Приложение использует следующие источники данных:

- **data.xlsx** - основные данные о товарах (ставки пошлин, объемы производства и потребления)
- **easToProduct** - маппинг кодов ТН ВЭД на наименования товаров
- **товарные_файлы.xlsx** - статистика импорта по странам и годам

### Разработчикам

#### Основные классы:

- **MainController** - обработка HTTP-запросов
- **ProductService** - бизнес-логика анализа товаров
- **IProductService** - интерфейс сервиса товаров

#### Добавление новых товаров:

1. Добавьте запись в файл `easToProduct` (формат: `наименование-кодТНВЭД`)
2. Создайте файл с данными импорта в папке `data/` (формат: `наименование.xlsx`)
3. Добавьте данные о товаре в `data.xlsx`
